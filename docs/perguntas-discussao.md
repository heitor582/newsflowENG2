# Perguntas para discussão em sala

As quatro perguntas seguem a estrutura solicitada. A primeira foi adaptada à regra de agendamento do NewsFlow, pois este domínio não possui reembolso.

1. Se a antecedência mínima para agendar mudasse de 15 para 30 minutos, quantos cenários vocês mudariam? Onde exatamente?
2. Mostre um cenário que quebraria se outro fosse executado antes dele.
3. Por que este passo está no Contexto e não dentro do cenário?
4. O que este cenário garante que o código, sozinho, não garantiria?
